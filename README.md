# Transformar ideas en acción con Copilot Chat (Básico)

Este curso enseña a los estudiantes cómo empezar con Microsoft 365 Copilot Chat (Básico), crear prompts efectivos y utilizar sus funciones impulsadas por IA para mejorar la productividad, agilizar el trabajo y colaborar de forma segura en tiempo real.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

Capítulo 1
- [Diseño y refinamiento de prompts para analizar una situación de negocio](Capitulo01/README.md#diseño-y-refinamiento-de-prompts-para-analizar-una-situación-de-negocio)
  - Descripción: En el contexto de CIBEST CAPITAL, los participantes utilizarán Microsoft Copilot Chat (Básico) para analizar qué factores están influyendo actualmente en las decisiones de inversionistas latinoamericanos que buscan diversificar internacionalmente su patrimonio. Comenzarán con un prompt sencillo, revisarán sus limitaciones y lo refinarán incorporando contexto, objetivo, fuentes o información de referencia, audiencia y formato esperado; posteriormente modificarán extensión y presentación para observar cómo pequeños cambios en las instrucciones alteran el resultado. La actividad utilizará únicamente información pública, no incluirá archivos ni información interna y finalizará con una comparación entre el prompt inicial y el refinado para identificar qué elementos aportaron mayor precisión, contexto y utilidad.
  - Duración estimada: 12 min

Capítulo 2
- [Análisis de la experiencia digital de inversionistas internacionales](Capitulo02/README.md#análisis-de-la-experiencia-digital-de-inversionistas-internacionales)
  - Descripción: Los participantes investigarán con Microsoft Copilot Chat (Básico), utilizando exclusivamente información pública, qué capacidades y experiencias digitales ofrecen actualmente distintas organizaciones de wealth management y servicios de inversión, organizando los hallazgos por categorías como consulta de portafolio, reportes, alertas, documentos, comunicación con asesores y contenidos educativos. Después revisarán las fuentes y transferirán explícitamente los hallazgos a Idea Coach para generar alternativas que podrían explorarse para mejorar la experiencia digital de clientes latinoamericanos de CIBEST CAPITAL, evaluando ventajas y dificultades hasta seleccionar tres ideas para exploración posterior, sin asumir ni afirmar qué funcionalidades posee actualmente la organización.
  - Duración estimada: 20 min

Capítulo 3
- [Análisis de acontecimientos económicos y escenarios what-if](Capitulo03/README.md#análisis-de-acontecimientos-económicos-y-escenarios-what-if)
  - Descripción: Los participantes utilizarán Microsoft Copilot Chat (Básico) para investigar un acontecimiento económico vigente seleccionado para la sesión mediante información pública reciente y fuentes confiables, identificando hechos, variables económicas o mercados relacionados, interpretaciones respaldadas y aspectos todavía inciertos. A partir de los hallazgos construirán tres escenarios hipotéticos what-if —base, alternativo favorable y alternativo adverso— con supuestos explícitos, variables o indicadores que convendría monitorear y posibles efectos a analizar, manteniendo separados los hechos observados de las hipótesis; finalmente organizarán los resultados como una propuesta ejecutiva de aproximadamente cinco diapositivas para una reunión interna de CIBEST CAPITAL, incluyendo contexto, hallazgos, escenarios, indicadores y preguntas para discusión.
  - Duración estimada: 20 min

Capítulo 4
- [Gestión de comunicaciones ante una interrupción temporal de un servicio digital](Capitulo04/README.md#gestión-de-comunicaciones-ante-una-interrupción-temporal-de-un-servicio-digital)
  - Descripción: Los participantes trabajarán con una ficha ficticia de interrupción temporal de una funcionalidad digital utilizada por clientes de CIBEST CAPITAL y emplearán Microsoft Copilot Chat (Básico) para analizar el impacto potencial, diferenciar datos proporcionados, cálculos derivados y supuestos, identificar información pendiente y establecer una prioridad temporal sin inventar la causa técnica del incidente. Posteriormente transferirán la información validada a un agente basado en Corporate Communications Crafter para preparar comunicaciones dirigidas a TI/desarrollo y a equipos internos/comerciales, utilizarán la capacidad Crear de Microsoft Copilot para generar una infografía destinada a usuarios externos y redactarán con Copilot Chat el correo que la acompañará, comunicando únicamente información confirmada, alternativas temporales y el próximo punto de actualización.
  - Duración estimada: 23 min

Capítulo 5
- [Análisis de incidencias operativas y generación de un reporte ejecutivo](Capitulo05/README.md#análisis-de-incidencias-operativas-y-generación-de-un-reporte-ejecutivo)
  - Descripción: Los participantes analizarán con Microsoft Copilot Chat (Básico) un conjunto ficticio de aproximadamente 20 a 30 observaciones operativas relacionadas con información incompleta, datos inconsistentes, solicitudes duplicadas, aclaraciones pendientes, errores de captura y otras situaciones recurrentes. Primero ejecutarán una indicación inicial para identificar patrones y categorías, después utilizarán Prompt Coach para mejorarla y comparar la calidad del nuevo análisis, y posteriormente priorizarán incidencias mediante criterios de frecuencia, impacto potencial, urgencia y afectación al proceso, diferenciando hallazgos respaldados de interpretaciones que requieren información adicional; finalmente generarán un plan de acción, un resumen ejecutivo para responsables operativos y una versión consolidada en una Página de Copilot como insumo para una reunión de revisión.
  - Duración estimada: 22 min
